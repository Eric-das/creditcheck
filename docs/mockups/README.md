# UI Mockups

Static HTML mockups of the intended interface. **Sample data, not a working build** — open the files in a browser to view.

| File | Screen | Notes |
|------|--------|-------|
| `01-connect-preview.html` | **Connect to Sage** (first run) | Auto-detects Sage, auto-configures the ODBC DSN, read-only sign-in. The hardest screen to build well — onboarding friction is the #1 risk. |
| `ui-preview.html` | **Dashboard · Investigation · Proposal** | Tabbed. Dashboard = suspicious-account list with engine verdicts; Investigation = allocation story line + conservation check + evidence intake + Outlook scan; Proposal = read-only proposed actions (human posts in Sage). |

All sample data in the mockups (account codes, customer names, amounts, transaction numbers) is fictional.

See [`../vision.md`](../vision.md) for the end-state and [`../../README.md`](../../README.md) for the engine scope.
